# Decentralized P2P Academic Resource Sharing Platform

A platform for students to share notes and research papers using IPFS decentralized storage with Proof of Contribution token system.

## Features
- ✅ Decentralized storage using IPFS
- ✅ Token rewards for quality content (Proof of Contribution)
- ✅ Peer verification system
- ✅ Quality score calculation
- ✅ User reputation management

## Technology Stack
| Layer | Technology |
|-------|------------|
| Backend | Spring Boot 2.7, Java 17 |
| Database | MySQL 8.0 |
| Frontend | Thymeleaf, Bootstrap 5 |
| Storage | IPFS Kubo 0.24 |
